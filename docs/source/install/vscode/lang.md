# VSCode の言語を日本語にする

```{note}
　VSCode をインストールしていない場合は
[VSCode をインストールする](./index.md)
を参照してください．
```

　VSCode のデフォルト言語は「英語」です．日本語にしたい場合は以下の手順に従って作業を行ってください．

1. **VSCode を起動する**<br>
    ```{note}
    すでに VSCode が起動している場合は次に進んでください．
    ```
    - Windows の場合はスタートメニューに「vscode」を入力して候補に上がる VScode をクリックして起動してください．

1. **コマンドパレットから言語設定コマンドを実行する**<br>
    - 起動している VScode 上で，キーボードショートカット「Control + Shift + P」を行ってください．「コマンドパレット」と呼ばれる `>` から始める検索バーのようなインターフェースが表示されます．
    - コマンドパレットの `>` の後に **`configure`** と入力してください．
        <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_lang1.png?raw=true"/>
    - すると、コマンドパレット下に候補として **`Configure Display Language`** が表示されるので、この項目をクリックしてください．
        <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_lang2.png?raw=true"/>
    - するとこのように言語の選択項目が表示されます．「日本語」をクリックしてください．
        <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_lang3.png?raw=true"/>
    - このようなポップアップが表示されます．「Restart」ボタンをクリックすると VScode が再起動します．
        <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_lang4.png?raw=true"/>
    - しばらくすると VScode は自動的に再起動します．再起動後の VScode が日本語になれば成功です！
        <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_lang5.png?raw=true"/>
