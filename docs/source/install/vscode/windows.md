# Windows 11 で VSCode をインストールする

1. **VScode をダウンロードする**<br>
    　以下のリンクをクリックして VScode ダウンロードサイトを開いてください．

    - [VSCode のダウンロードサイトに移動する](https://code.visualstudio.com/download)

    　そして、**Windows** と書かれているボタンをクリックして，Windows 版 VSCode インストーラーをダウンロードしてください．このボタンをクリックするとインストーラーがダウンロードされます。

    <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/download_vscode.png?raw=true"/>

1. **VSCode をインストールする**<br>
    - エクスプローラーから「ダウンロード（Downloads）」フォルダを開いてください．
    - ダウンロードフォルダにダウンロードされた VSCode インストーラー をダブルクリックするか，右クリックしたときに表示される 「開く」 をクリックしてインストーラーを起動してください．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/download_vscode2.png?raw=true"/>
    - 起動すると，このようなセットアップ画面が表示されます．
「同意する」にチェックを入れて「次へ」をクリックしてください。
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install1.png?raw=true"/>
    - 次に進むとインストール先の指定に入りますが，ここは何も触れずに「次へ」をクリックしてください．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install2.png?raw=true"/>
    - 次に進むとスタートメニューを作るか否かを選択できます．ここも何も触れずに「次へ」をクリックしてください．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install3.png?raw=true"/>
    - 次に進むと VScode のインストールに関する追加機能を選択できます．ここも何も触れずに「次へ」をクリックしてください．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install4.png?raw=true"/>
    - 次に進むと VScode のインストール項目の確認が表示されます．ここで問題がなければ「インストール」をクリックしてください．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install5.png?raw=true"/>
    - すると VScode のインストールが始まります．終了するまでまちましょう．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install6.png?raw=true"/>
    - VScode のインストールが成功するとこのような画面が表示されます．「Visual Studio Code を実行する」にチェックが入っていると，「完了」ボタンをクリックすると VScode が起動します．
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_install7.png?raw=true"/>
    - 「完了」ボタンをクリックすると VScode がこのように起動します．これで VScode のインストールは完了です！ 
        <img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_window.png?raw=true"/>
