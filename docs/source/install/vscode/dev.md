# 開発用拡張機能をインストールする

```{note}
　VSCode をインストールしていない場合は
[VSCode をインストールする](./index.md)
を参照してください．
```
```{note}
　このセクションは以下のユーザー向けの作業になります．ローカルで開発を行っているユーザーはこのセクションをスキップして構いません．

- WSL, Docker などの仮想環境上で開発を行うユーザー
```

1. **VSCode を起動する**<br>
    ```{note}
    すでに VSCode が起動している場合は次に進んでください．
    ```
    - Windows の場合はスタートメニューに「vscode」を入力して候補に上がる VScode をクリックして起動してください．

1. **VScode の画面左端にある 田みたいなマーク 「拡張機能」をクリックしてください。**<br>
    <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_ext1.png?raw=true"/>

1. **拡張機能メニューの検索バーをクリックしてください．**<br>
    <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_ext2.png?raw=true"/>

1. **検索バーに `Remote` と入力してください**<br>
    検索結果に「Remote Development」という項目が表示されます．
    <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_ext3.png?raw=true"/>

1. **青い「インストール」ボタンをクリックしてこの拡張機能をインストールしてください**<br>
    <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_ext4.png?raw=true"/>
    <br>
    インストールが完了すると「インストール」ボタンが消え，拡張機能アイコンの上にテレビモニターのようなアイコンが表示されます．これで拡張機能のインストールは完了です！
    <br><img src="https://github.com/horilaboratory/robot_project/blob/main/imgs/vscode_ext5.png?raw=true"/>
