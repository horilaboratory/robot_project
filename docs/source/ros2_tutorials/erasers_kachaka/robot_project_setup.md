# Robot Project Kachaka のセットアップ方法

1. **充電ドッグから Kachaka を取り出す**<br>

    充電中の Kachaka を充電ドッグから取り出してください．

    ```{note}
    もし Kachaka の電源がついていない場合，Kachaka の電源ボタンを長押しして電源をつけてください．
    ```

1. **Kachaka を停止状態にする**<br>

    Kachaka は一定時間充電ドッグから離れると自動的に充電ドッグに戻ろうとします．これを防止するため Kachaka の電源ボタンを1度押して，Kachaka の LED リングが黄色になることを確認してください．

1. **Base シェルフを用意する**<br>

    添付画像のような「Base シェルフ」を用意してください．

1. **ルーターとバッテリーを用意する**<br>

    Base シェルフにポケット Wi-Fi ルーターとモバイルバッテリーを用意してください．

1. **ケーブルを用意する**<br>

    Base シェルフ内に収まる長さの USB C ケーブルと Ethernet ケーブル，そして長めの Ethernet ケーブルをもう１本用意してください．

1. **短い Ethernet ケーブルを Kachaka に接続する**<br>

    Ethernet ポート搭載モデルの Kachaka に短い Ethernet ケーブルを接続してください．

1. **Ethernet ケーブルがつながったままの Kachaka に Base シェルフを積載する**<br>

    Base シェルフの前に Kachaka を押して，Kachaka にむかって「ねぇカチャカ，家具を載せて」と話しかけてください．すると Kachaka が Base シェルフを積載しようとします．

    このとき，Kachaka が Base シェルフの積載に失敗しないように Base シェルフを押さえておいてください．

1. **ルーターに Ethernet ケーブルを接続する**<br>

    Base シェルフ側面から Kachaka につながっている Ethernet ケーブルを伸ばし，WIi-Fi ルーターに接続してください．

1. **ルーターの電源を入れる**<br>

    モバイルバッテリーと Wi-Fi ルーターを USB C ケーブルで接続して，モバイルバッテリーの電源ボタンを長押しして Wi-Fi ルーターの電源を入れてください．
